# Prompt template for a focused Codex task

`Read PROJECT_BRIEF.md. In <exact file or feature>, change <desired result>. Keep <constraints>. Done means <acceptance criteria>. Verify with <command or device width>.`

Example:

`Read PROJECT_BRIEF.md. In public/portal.css, increase spacing between sidebar icons and labels. Keep the purple theme and the 390px layout. Done means all navigation labels remain readable at desktop and 390px. Verify with npm run validate.`
